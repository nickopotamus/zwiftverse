# zwiftverse: Tidy httr2 Clients for the Zwift, ZwiftPower and ZwiftRacing.app APIs

Reverse-engineered, unofficial R clients for three Zwift-ecosystem APIs:
the Zwift game API (us-or-rly101.zwift.com), ZwiftPower and
ZwiftRacing.app. Typed wrappers return tibbles; low-level accessors
reach unwrapped endpoints; an on-disk TTL cache avoids re-fetching
stable data. None of these are official APIs - they are
reverse-engineered and may break on any upstream change.
